# About Runs

Every run in your projects, newest first, with its workflow version, state, submitter, duration and cost. The list pages from the server and refreshes while runs are live.

## How do I filter?

Use the state filters and the search box, and sort by a column header.

## How do I rerun a run?

Open it: **Re-run** opens the launch form with its version and parameters, and **Resume**, when offered, starts a new run from its cache so finished tasks are not run again.

## Can I script this?

Yes: `biffix runs submit`, `list`, `show`, `follow` and `cancel` use the same API, documented under API in the sidebar.
