# About this experiment

Its runs, their reports side by side, a sample × run table and the summed cost.

## How do I add a run?

**New run in this experiment** launches one into it, or use **Add to experiment** on any run in the same project.

## Where does the sample table come from?

Each run's sample ids, read from its samplesheet.

## Does removing a run delete it?

No. **Experiment ▾ → Remove from** on the run's page only takes it out of this experiment.
