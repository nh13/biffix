# About Data

Browse the configured data sources (S3 locations) and your project bucket, as the launch form's file picker does.

## Where are data sources configured?

In the deploy config: each one is a bucket and prefix that biffix may read.

## How do I upload?

From the launch form's file picker: **Upload files…** sends files to your project bucket, and an interrupted upload can be resumed after a reload.

## Can I preview a file?

Tables, text, images, PDFs and HTML reports open in the viewer.
