# About this experiment

Its analyses, their key results side by side, which samples ran in which analysis, and what it all cost.

## How do I add an analysis?

**Start an analysis in this experiment** starts one already in it. To add one you already ran, open it and choose **Add to experiment**.

## How do I compare results?

**Results across analyses** lines up each analysis's key results. The samples table shows which samples ran where.

## Can I take an analysis out?

Yes: on the analysis's own page, **Experiment ▾**, then **Remove from** it. The analysis and its files are kept.
