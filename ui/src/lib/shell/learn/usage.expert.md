# About Usage

What runs cost over a period, grouped by month, workflow, submitter, instance type or project.

## How is cost worked out?

Each job's instance time at its instance type's on-demand or spot price, plus its EBS volume; the coordinator job counts too.

## Why does a run's cost change?

It grows while the run is live and settles once every job has ended.

## Can I export it?

Yes: download the table as CSV.
