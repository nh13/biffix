# About this analysis

One page per analysis: how far each sample got, the key results and QC when it finishes, what it cost and, if something failed, what went wrong and what to try.

## What if a sample failed?

**What went wrong** names the sample and the step in plain words. **Try again** does what the failure calls for, as the line under it says: it picks up where the analysis left off (finished samples are kept), starts it again with the same samples and settings, or, as **Fix and try again**, opens the launch form to change the samples or options first.

## Where are my results?

Key results show as cards you can open here. **All files** lists everything the pipeline wrote to your project's storage.

## How do I share it?

**Share → Copy link** copies the page's link. Anyone signed in with access to this project can open it, on any device.
