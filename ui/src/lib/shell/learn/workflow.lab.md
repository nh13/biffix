# About this pipeline

What the pipeline does, what it needs from you and what it produces, as its authors describe it. The **Run** tab is the step-by-step launch.

## What samples does it take?

The **About** tab says what input it expects, usually FASTQ files. The launch builds the samplesheet from the files you choose.

## Which version will I run?

The one this page is for. **Start** on a Pipelines card opens the newest _released_ version (or the newest, if none is released yet); when there are several, **Version** above the tabs switches. Every analysis records the exact version it ran.

## Who do I ask about it?

The contact its author named, else the support contact an admin set in Settings: a failed analysis offers to **Ask** them, and **Copy report for support** gathers what they need to help. With neither, whoever runs biffix for your lab.
