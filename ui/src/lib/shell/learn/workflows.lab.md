# About pipelines

A pipeline is a versioned analysis, such as bulk RNA-seq or variant calling. You choose one, add your samples, and biffix runs it for you.

## How do I start an analysis?

Click **Start** on a card, or **Start an analysis** on My work, and follow the steps. **Start** uses the pipeline's newest released version. Pipelines still in development (nothing released) are hidden unless you turn on **Developer**.

## What does Verified mean?

The pipeline's author vouches for it. biffix doesn't check it, so ask the author if you're unsure.

## Where do results go?

To your project's storage. Each finished analysis shows its key results first, then every file it wrote.
