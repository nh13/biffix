# About Settings

Your view and display preferences and, for developers, the site's title and logo, engines and alert recipients, and for admins, reference bundles and the support contact.

## Who can change site settings?

Developers and Admins change the title, logo and alert recipients; only Admins change reference bundles and the support contact. The engines are the deploy's, listed here but not changed here. The server refuses anyone else's change.

## How do I register a reference genome?

**References** lists the bundles: each is a named set of files (FASTA, index, annotation) that fills a workflow's reference parameters.

## How do alerts work?

Alert recipients get an email from biffix's alarms. Each address confirms once before it receives anything.
